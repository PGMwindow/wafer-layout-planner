# Wafer Layout Game

A simple browser-based wafer layout planner designed for GitHub Pages.

## Current features

- 9 rectangular dies: D1–D9
- Independent width and height controls for every die
- Drag dies from the tray onto the wafer
- Rotate the selected die in 90° steps
- Recommended placement radius: 60 mm
- Maximum allowed radius: 75 mm
- Real-time boundary checking
- Real-time die-to-die overlap detection
- Layout status summary
- No backend required

## Run locally

Open `index.html` in a modern web browser.

## GitHub Pages

Upload these files to a GitHub repository and enable GitHub Pages from the repository settings.

## Files

- `index.html`
- `style.css`
- `script.js`

The current die sizes are placeholder defaults and can be edited directly in the web interface.
